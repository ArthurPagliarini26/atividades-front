Banco de Dados

Sobre o curso

A disciplina de Banco de Dados ensina como armazenar, organizar e gerenciar informações utilizando Sistemas Gerenciadores de Banco de Dados (SGBDs), como o MySQL.

O que aprendi com a matéria

Aprendi a criar bancos de dados e tabelas, utilizar comandos SQL como SELECT, INSERT, UPDATE e DELETE, criar relacionamentos entre tabelas, utilizar chaves primárias e estrangeiras e desenvolver consultas para manipular informações.
