Front-end

Sobre o curso

A disciplina de Front-end aborda o desenvolvimento da interface de sites e aplicações web utilizando HTML, CSS e JavaScript.

O que aprendi com a matéria

Aprendi a criar páginas web utilizando HTML, estilizar elementos com CSS, desenvolver interatividade com JavaScript, criar layouts responsivos e melhorar a experiência do usuário.
